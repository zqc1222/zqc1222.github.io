# Laurence Zhang · Personal website

张群策的科研个人主页，面向大模型智能体与 AI for Science 方向。

## Preview

No build step or dependencies. Run `python3 -m http.server 8080` from the repository root and open `http://localhost:8080`.

## Files

- `index.html`: profile, research records, engineering projects and learning-station links.
- `profile.html`: printable personal overview. Use the print button to save a PDF.
- `styles.css`: responsive layout, reduced-motion and print styles.
- `script.js`: mobile navigation, clipboard feedback and printing.
- `assets/science-orbit.svg`: decorative vector artwork, not research data.

## Content maintenance

Entry year is **2025**. Research and manuscript status must reflect confirmed facts. The chemistry agent is ongoing; photometry is delivered and confidential; the two manuscript-related works are unpublished. Do not add unverified metrics, author order, submission or acceptance claims. Update the profile and homepage together when new evidence becomes available.

The three learning links use the existing study site. This repository does not change its access settings.

The site is plain static HTML and can be published from the root of `main` with GitHub Pages. It uses no external fonts, tracking, or client-side framework.
